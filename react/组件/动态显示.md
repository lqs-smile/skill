






	控制 <Draggable> 组件的显示隐藏有几种常见方法：

##  方法 1：使用状态控制（推荐）
	
``` tsx
import Draggable from 'react-draggable'
import { FC, useRef, useState } from 'react'

const WindowDrag: FC<WindowDragProps> = ({ 
title, children }) => {
  const nodeRef = useRef<any>(null)
  const [visible, setVisible] = useState
  (true)  // 控制显示隐藏

  if (!visible) return null  // 隐藏时不渲染

  return (
    <Draggable cancel=".no" nodeRef={nodeRef}>
      <div
        ref={nodeRef}
        style={{
          zIndex: 99999,
          cursor: 'move',
          position: 'absolute'
        }}
      >
        <h3 className={styles.title}>
          <span>{title}</span>
          <span className={styles.close} 
          onClick={() => setVisible(false)}>
            关闭
          </span>
        </h3>
        <div className="no">{children}</div>
      </div>
    </Draggable>
  )
}
```

## 方法 2：使用 CSS 控制（保留 DOM）

```tsx
<div style={{ display: visible ? 'block' : 
'none' }}>
  <Draggable ...>
    {/* ... */}
  </Draggable>
</div>
```
## 方法 3：条件渲染（外部控制）

```tsx
{showModal && (
  <WindowDrag title="标题">
    内容
  </WindowDrag>
)}
```


## 对比

方法 特点 适用场景 
* useState + return null 完全移除 DOM，节省资源 不频繁切换的场景
* CSS display 保留 DOM，切换快 需要频繁显示隐藏
* 外部条件渲染 组件级控制 父组件管理多个弹窗
