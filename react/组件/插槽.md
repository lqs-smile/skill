

### 总结

- **默认插槽** → `props.children`
    
- **具名插槽** → 自定义 props 传递 JSX
    
- **带数据的插槽** → render props（函数作为 children 或特定 prop）





### 1. 默认插槽：`children`

任何在组件标签内部嵌套的内容都会被自动作为 `children` prop 传递给组件。

**父组件使用：**
```jsx
import Card from './Card';

function App() {
  return (
    <Card>
      <h2>这是传递的内容</h2>
      <p>相当于 Vue 的默认插槽</p>
    </Card>
  );
}
```


**子组件 `Card` 接收：**
```jsx

function Card({ children }) {
  return (
    <div className="card">
      {children}  {/* 渲染传递的内容 */}
    </div>
  );
}

```


### 2. 具名插槽：通过自定义 props 传递 JSX

如果需要多个插槽位置（如 header、footer），可以定义不同的 props 来接收 JSX。

**父组件：**
```tsx
<Layout
  header={<header>页眉</header>}
  footer={<footer>页脚</footer>}
>
  <main>主要内容</main>  {/* 依然作为 children 传递 */}
</Layout>
```



**子组件 `Layout`：**
```tsx
function Layout({ header, footer, children }) {
  return (
    <div>
      <div className="header">{header}</div>
      <div className="content">{children}</div>
      <div className="footer">{footer}</div>
    </div>
  );
}
```

### 3. 更灵活的渲染：Render Props

如果需要将组件内部的数据传递给插槽内容，可以使用 render props（函数作为 children 或 props）。


**父组件：**

```tsx
<List
  data={items}
  renderItem={(item) => <li>{item.name}</li>}
/>
```


**子组件 `List`：**
将数组的item(实参)传给children的item(形参)
``
```tsx
function List({ data, renderItem }) {
  return (
    <ul>
      {data.map(item => renderItem(item))}
    </ul>
  );
}
```
