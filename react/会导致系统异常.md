


## useEffect中改变自身的依赖
由于不断返回的新数组(map返回不一样的地址)
不断的刷新当前页面，不一会儿就栈溢出了

```javascript
  useEffect(() => {
    setStoreInfoList(
      choiceStoreList.map((item: any) => {
        return {
          storeName: item.storeName,
          storeCode: item.storeCode
        }
      })
    )
    setStaffInfoList(
      choiceStaffList.map((item: any) => {
        return {
          staffName: item.staffName,
          staffCode: item.staffCode,
          storeName: item.storeName,
          positionName: item.positionName
        }
      })
    )
  }, [setStaffInfoList, setStoreInfoList])
```
