## vscode + cline

选择自带key - 选择copilot

选择mcp servers 会生成一个 server配置

```json
{
  "mcpServers": {
    "API 文档": {
      "command": "cmd",
      "args": [
        "/c",
        "npx",
        "-y",
        "apifox-mcp-server@latest",
        "--project=<你的项目ID>"
      ],
      "env": {
        "APIFOX_ACCESS_TOKEN": "<你的访问令牌>"
      }
    }
  }
}
```





## 开始工作（重点）



### 生成TS数据模型和请求接口的函数

* 提示词：通过MCP获取用户相关的API，并生成对应的TypeScript接口定义和请求函数。
* AI能做的事：根据aip文档的请求/响应结构，自动生成前端后端的类型定义、api调用的代码

### 同步文档/代码
* 提示词：检查API文档中产品接口是否有更新，并同步更新我项目里的`Product`模型
* AI能做的事：对比本地代码与最新文档，自动为你的数据模型添加新增字段，或标注已废弃的字段


### 生成测试代码

* 提示词：根据MCP中的登录接口文档，为我生成一套包含正常和异常情况的Jest测试代码。
* AI能做的事：基于接口的路径、参数、响应，自动编写出覆盖不同场景的单元测试或接口测试用例。

### 解释与搜索

* 提示词：在API文档里搜索所有和‘支付’相关的接口，并解释它们的调用流程。
* AI能做的事：快速在复杂的文档中定位信息，并以清晰的方式为你总结，帮助你理解业务流程。




## 使用技巧



### 管理多个项目（微服务中会遇到）

在mcpServers配置对象中并列添加多个配置，并且给他们起不同的名字，例如审方api、培训api、导购宝api等等

向ai提问时：带上某个具体api，这样效率更高



### 保持数据新鲜

mcp会默认缓存api文档已提高速度，当你的api文档更新后，在提示词中加上`请刷新mcp缓存，重新读取最新文档` 就可以确保ai拿到的是最新的数据


### 注意令牌安全
1. 不要提交到仓库
2. 一种比较好的做法是：从json中删除APIFOX_ACCESS_TOKEN，改为电脑环境变量中设置一个重名的变量cline会自动读取


### window系统特别提示
如果遇到问题，请确认你使用的是上面提供的包含 `“command”: “cmd”` 的Windows专用配置格式


### 支持访问本地/公开的文档
除了连接Apifox项目，该工具也支持直接使用本地的 `swagger.json` 文件或一个公开的OpenAPI文档URL。只需将配置中的 `“--project”` 参数替换为 `“--oas=文件路径或URL”` 即可，且无需访问令牌。
