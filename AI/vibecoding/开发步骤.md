


## 一、新建计划plan


1. 我们首先让ai帮我出一个计划
	1. 代码分支为： feat/studyModuld-lqs
	2. 需求文档为：产品文档 => 人工转为前端文档

2. 设置plan标准(每个计划都会走这个标准)， 可以封装为指令(me:plan)

```markdown
# 项目规划

## 功能拆解
尽可能详细，并且按照新特性逐步开发

##  性能优化
在设计需求实现的时候，尽量考虑性能瓶颈点，并且进行优化方案的探讨

## 其他

## 产出
规划完后，将规划文档输出至·plan文件中


```


3. 通过斜杠选择到我们这个指令：me:plan
	1. 开始提要求：实现xxx（我们的需求，可以是我们整理的需求文档）
	2. ai会根据指令内容来来构建计划


## 指定具体的技术方案


``` Markdown

## 技术方案

### 表格渲染器
	1. 渲染底层方式选用canvas渲染
    2. 滚动通过遮罩div借用滚动条，以此实现canvas可是渲染区的渲染逻辑
    3. 表格单元格，需要使用插件化协议，支持动态扩充不同类型的单元格

## 前端框架

基于nextjs16 + shadcn + tailwindcss


## 服务端

prisma7 + Postgresql18


## 运维层

	— 基于docker compose 启动pg18完成基础设施的启动
	



```
