## Agent

ai程序员本身，你给他需求，他自己拆任务，想方案，写代码，做测试，自行修复异常，统筹全局的中心


## skill
给你的ai程序员进行岗前培训，培训之后，成为某个领域的专家，和标准化工作流，零配置，加载就会生效，直接就输出质量


## MCP
Model Context Protocol(模型上下文协议),连接外部资源的接口

作用：操控浏览器，连接数据库，调api

* 统一协议标准接
* 连接数据库浏览器
* 实时获取外部数
* 调用第三方 API据



## rules

工程规范，目录文件规范和编码规范
1. 统一代码风格
2. 遵守项目约定
3. 跟随仓库版本管理
4. 团队协作风格一致
