

## 安装

``` shell
mkdir myapp

cd myapp

npm init

npm install express

```





## 启动服务器
创建一个app.js作为入口文件

```js

const express = require('express')
const app = express()
const port = 3000

app.get('/', (req, res) => {
  res.send('Hello World!')
})

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`)
})

```



## 自动重启服务器

因为每次文件变更都需要重启服务器才能产生效果，但是在开发中这就比较麻烦，最好是能监听到文件变更能自动重启服务器的功能


```shell
npm i nodemon -s
```
