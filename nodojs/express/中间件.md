

## 概念


请求对象：req
响应对象：res
交接函数：next,是express路由中一个函数，当被调用时，他会在当前中间件之后执行中间件


中间件函数：可以访问应用请求到响应的生命周期中的req和res以及调用next函数

中间件函数可以做什么？
1. 执行任何代码
2. 更改请求和响应对象
3. 结束请求
4. 调用堆中下一个中间件


如果当前中间件函数没有去结束掉请求，则它必须调用next函数，将控制权传递给下一个中间件函数，否则请求将被挂起


总结：`中间件就是整个请求中的一个节点，这个节点可以获取到请求对象，可以响应请求，也可以把请求交给下一个节点`




## 中间件函数的编写

```js
const myLogger = function (req, res, next) {


  // 添加自定义属性
  req.requestTime = Date.now();
  req.userId = '12345';
  req.customData = { some: 'info' };
  
  
  // 修改请求对象的属性
  console.log("打印log中间件");
  
  
  // 返回响应对象之后不应该再继续调用next函数了
  if (!req.token) {
    return res.status(403).send('Forbidden');
  }else{
	 // 方式1：直接返回JSON
	  res.json({ message: '直接响应' });
	  // 方式2：返回文本
	  // res.send('直接响应');
	  // 方式3：返回状态码
	  // res.status(401).send('未授权');
	  }
	  return

  // 不使用res的话就得调用next函数交给下一个中间件处理
  next();

};

  

module.exports = myLogger;
```


### 注意

* 如果执行到最后一个中间件还是没有做出响应的话，会返回404状态码
* 中间件发生了错误，不会打断执行，会以next(error)，去寻找后续的`错误中间件`，如果没有的话就报500
