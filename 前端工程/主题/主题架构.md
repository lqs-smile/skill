


:root,指的是根元素，在html中就是html标签

:root[theme-mode='right'], 白天模式
:root[theme-color='#0052D9']，主题色为0052D9
[theme-color='#0052D9']：属性选择器，即 当标签上的属性为theme-color为#0052D9时，这个样式生效
``` html
<html lang='en' theme-mode="dark"></html>
```

