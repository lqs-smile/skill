


## 颜色：
先分大方向，再分小方向，使用编号区分

例如：
1. 字体 -  灰白色 灰白1、灰白2、灰白3
2. 字体 -  灰黑色 灰黑1、灰黑2、灰黑3



## 案例

```css
:root {
  /* 基础调色板（可扩展） */
  --gray-900: #171717;
  --gray-700: #404040;
  --gray-400: #a3a3a3;
  
  /* 语义化包装 */
  --color-text-primary: var(--gray-900);
  --color-text-secondary: var(--gray-700);
  --color-text-muted: var(--gray-400);
}
```


字体颜色
-- 主文本颜色：var(--td-font-gray-1);
-- 次文本颜色：var(--td-font-gray-2);
-- 占位符文本颜色：var(--td-font-gray-3);
-- 禁用文本颜色：var(--td-font-gray-4);
-- 反色文本颜色：#fff;
-- 品牌文本颜色：var(--td-brand-color-7);
-- 链接文本颜色：var(--td-brand-color-8);

背景颜色

primary:主要的
secondary：次要的
