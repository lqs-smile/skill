


## 🎨 推荐的命名方法

### 1. **基于设计系统的语义命名**

```css
/* 按功能/语义 */
--color-text-primary      /* 主要文本 */
--color-text-secondary    /* 次要文本 */
--color-text-tertiary     /* 辅助文本 */
--color-text-disabled     /* 禁用状态文本 */
--color-text-link         /* 链接文本 */
--color-text-error        /* 错误文本 */
--color-text-success      /* 成功文本 */
```

### 2. **基于UI层次结构**

```css
/* 按UI层级 */
--color-background-primary    /* 主要背景 */
--color-background-secondary  /* 次要背景 */
--color-surface               /* 表面/卡片背景 */
--color-border                /* 边框颜色 */
--color-divider               /* 分隔线颜色 */
```



### 3. **实用但具体的命名**

```css
/* 具体但不抽象 */
--color-brand-primary      /* 品牌主色 */
--color-brand-secondary    /* 品牌辅色 */
--color-neutral-50         /* 中性色阶 */
--color-neutral-100
--color-neutral-200
--color-neutral-900
```
